# Tool radar: engines, libraries and formats for an autonomous editor

Date of reading: 2026-11-26. Author: tool radar agent. Everything below was read on that date from registry metadata (npm, PyPI, Homebrew formulae API), the GitHub search API (stars, licence tag, last push), or the official page named in the row. Where a page could not be read the row says so and the item is also in "Could not read".

## How to read this

- Way: a = PAGE library (runs in the headless Chromium made-clip page); b = ENGINE (program or Python worker run as a job); c = LIBRARY in editor or server (TS/WASM) or Python worker.
- "Weight" for npm packages is the `unpackedSize` field of the latest version (not what a bundler ships). For native tools it is unknown unless stated.
- "Stars" are GitHub stars from the search API on the read date; "unknown" means the repo was not in the batch read. Release cadence is shown only as the latest version date because release lists on github.com return 403 through the proxy.
- Licence "flags": GPL, AGPL, LGPL, NC (non-commercial), PAID, SA (source-available). The owner is one private person using the tools locally, so copyleft licences bind only if the editor is shipped to others; they are flagged because the project may be shared later. A tool run as a separate program (way b) is not linked into the editor, which keeps GPL out of the editor's own code.
- No row was run or installed. "Agent could" is the intended use, not a tested result. For page libraries (way a) the first test is always: can the animation be set to an exact time (seek) with no wall-clock? Not tested for any row.
- Already in the project (not repeated as findings): FFmpeg, Blender, Manim, three.js, GSAP, HyperFrames, Remotion (read separately), Mediabunny 1.66.0, Playwright, ComfyUI, @fontsource Hebrew fonts, Lottie renderer (listed as candidate in TECH_RADAR), ONNX Runtime Web, Transformers.js, MediaPipe (candidates).
