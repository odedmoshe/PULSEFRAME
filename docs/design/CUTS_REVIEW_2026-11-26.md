## 1. Reopen first

Order is by how much the reopening adds to an editor that works on its own for any kind of video (judgement of the reviewer, not a measurement).

1. C14, C15, C16 (assistant propose-only, excluded ops, allow-list summary): the assistant edits with the same ops as any agent (ADR-0027:21-34; `assistantContract.ts:44-85`).
2. C30 to C34 (agent approvals and owner-only routes): the agents named in GATES A and B act without asking (BLK:93).
3. C38 (model-written code and FFmpeg engines): already started in W8:37-62; the `engines` track is the remaining part.
