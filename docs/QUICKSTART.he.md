# הפעלה ראשונה במחשב Windows

> **מצב המדריך:** חלק א' (התקנה, בנייה, הפעלה ופתיחת העורך ב-Chrome) הושלם פעם אחת על Windows 11 עם Node 22.17, אחרי שני תיקונים שנמצאים עכשיו במאגר. חלקים ב' ו-ג' (זיהוי דיבור וקריינות) עדיין לא נוסו על Windows. אם שלב נכשל, העתיקו את הודעת השגיאה כמו שהיא.
>
> הפקודות נכתבו ל-PowerShell. בחלון **cmd** רגיל הן עובדות גם כן, חוץ משורות שמתחילות ב-`$env:` (בחלקים ב' ו-ג'); ב-cmd כותבים במקומן `set PF_SPEECH_PYTHON=...` בשורה נפרדת לפני `pnpm start`.

המדריך מחולק לשלושה חלקים. חלק א' מספיק כדי לראות את העורך. חלקים ב' ו-ג' מוסיפים זיהוי דיבור וקריינות, ואפשר לדלג עליהם.

## חלק א' — העורך (כ-15 דקות)

### 1. התקנות חד-פעמיות
פותחים **PowerShell** ומריצים שורה אחרי שורה:

```powershell
winget install OpenJS.NodeJS.LTS
```
```powershell
winget install Git.Git
```
```powershell
winget install Gyan.FFmpeg
```
```powershell
winget install Python.Python.3.12
```

סוגרים את PowerShell ופותחים מחדש (כדי שהתוכנות החדשות יזוהו), ואז:

```powershell
npm install -g pnpm@10.28.0
```

בדיקה שהכול מותקן — כל שורה צריכה להדפיס מספר גרסה:

```powershell
node --version; pnpm --version; ffmpeg -version | Select-Object -First 1; python --version
```

נדרש Node בגרסה 22.12 ומעלה.

### 2. הורדת הפרויקט

```powershell
git clone https://github.com/odedmoshe/pulseframe.git
```
```powershell
cd pulseframe
```
```powershell
git checkout claude/confident-planck-677xq5
```

### 3. התקנה ובנייה

```powershell
pnpm install
```
```powershell
pnpm exec playwright install chromium
```
```powershell
pnpm build
```

### 4. הפעלה

```powershell
pnpm start
```

בחלון יודפסו כמה שורות. מחפשים את השורה **Editor (owner)** ופותחים את הקישור שלצידה ב-Chrome. הקישור כולל מפתח גישה, ולכן הוא עובד רק מהמחשב הזה.

לעצירה: `Ctrl+C` בחלון PowerShell.

### 5. בדיקת כרטיס המסך (חשוב — זה מה שפותח את עבודת כרטיס המסך)
כשהעורך פועל (`pnpm start`), פותחים **ב-Chrome הרגיל** את הכתובת:

```
http://127.0.0.1:8787/gpu.html
```

הדף בודק מה הדפדפן מזהה (כרטיס מסך, קידוד בחומרה) ומריץ מדידת זמן קצרה אחת. לוחצים **העתקת התוצאה** ושולחים את הטקסט. שום דבר לא נשלח מהדף לשום מקום.

**אם בתוצאה כתוב `"vendor": "intel"`**, Chrome משתמש בכרטיס המובנה ולא ב-NVIDIA. כדי להעביר אותו: הגדרות Windows ← מערכת ← תצוגה ← גרפיקה ← בוחרים את Google Chrome ← אפשרויות ← **ביצועים גבוהים** ← שמירה, ואז סוגרים את כל חלונות Chrome ופותחים מחדש. (ההוראה הזאת לא נוסתה.)

### 6. בדיקת הדפדפן שמייצא
הייצוא רץ בדפדפן נפרד ונסתר. הפקודה הבאה בודקת אם גם הוא יכול להשתמש בכרטיס המסך (כדקה; ייתכן שיהבהב חלון לרגע):

```powershell
pnpm probe:gpu
```

שולחים את הטבלה שמודפסת.

### 7. אפקטים על כרטיס המסך (מסך ירוק, גל, עדשה, מערבולת, מראה, טשטוש זום, פוסטר, קווי מתאר, גליץ')
בעורך, בלשונית **קליפ** ← הוספת אפקט, האפקטים האלה זמינים רק אם הדפדפן עבר את בדיקת כרטיס המסך.

בייצוא אין צורך בהגדרה מיוחדת: כשבפרויקט יש אפקט כזה, השרת מחפש לבד, פעם אחת, דרך להפעיל את הדפדפן המייצא עם כרטיס מסך (ייתכן שחלון יהבהב לרגע), ומדפיס בחלון הפקודה באיזו דרך בחר. אם לא נמצאה דרך, הייצוא נכשל עם הסבר ולא יוצא בלי האפקט. (החיפוש האוטומטי עוד לא נוסה על Windows. אפשר לכפות דרך מסוימת עם `set PF_RENDER_GPU=window` לפני `pnpm start`.)

הפקודה `pnpm probe` בודקת דפדפן נסתר שרץ בלי כרטיס מסך, ולכן היא לא מראה את הכרטיס האמיתי; היא נשארת שימושית רק לבדיקת הסביבה שבה רץ הייצוא.

### 8. עדכון לגרסה חדשה
כשיש גרסה חדשה, סוגרים את העורך (`Ctrl+C` בחלון שבו הוא רץ) ומריצים מתוך תיקיית הפרויקט, שורה אחרי שורה:

```powershell
git pull
```
```powershell
pnpm install
```
```powershell
pnpm build
```
```powershell
pnpm start
```

**אחרי הפעלה מחדש של המחשב** העורך לא עולה לבד: מריצים שוב את ארבע הפקודות האלה מתוך תיקיית הפרויקט (הקישור של **Editor (owner)** מודפס מחדש בכל הפעלה).

**בלחיצה כפולה (מ-26.11.2026, עוד לא נוסה על Windows):** בתיקיית הפרויקט יש קובץ בשם `start-pulseframe.cmd`. לחיצה כפולה עליו מריצה את אותן ארבע פקודות לפי הסדר ומשאירה את החלון פתוח. אם הותקנו זיהוי דיבור או קריינות (חלקים ב' ו-ג'), הוא מפעיל את העורך איתם. אם שלב נכשל, החלון נשאר פתוח עם ההודעה.

"חלון הפקודה" הוא החלון השחור (PowerShell או cmd) שבו הקלדתם `pnpm start`. כל עוד העורך פועל, השרת מדפיס שם שורות; שם גם תופיע השורה `render worker: GPU effects use launch mode …` בפעם הראשונה שמייצאים פרויקט עם אפקט של כרטיס מסך.

### 10. בדיקת שבעת המעברים החדשים בכרטיס המסך (RTX 3050)
שבעה מעברים חדשים רצים על כרטיס המסך: **צריבת פילם**, **דליפת אור**, **כתם דיו**, **משיכת מכחול שמאלה**, **משיכת מכחול ימינה**, **דפדוף שמאלה** ו**דפדוף ימינה**. עד היום הם נבדקו רק על מעבד תוכנה בענן, אף פעם לא על כרטיס מסך אמיתי, ולכן אין לדעת עדיין איך הם נראים אצלכם. זו הבדיקה הראשונה.

1. סוגרים את העורך אם הוא פועל (`Ctrl+C`), ומתוך תיקיית הפרויקט מעדכנים כמו בסעיף 8, שורה אחרי שורה: `git pull`, `pnpm install`, `pnpm build`, `pnpm start`.
2. כשהעורך פועל, פותחים **ב-Chrome הרגיל** את דף בדיקת כרטיס המסך, כמו בסעיף 5: `http://127.0.0.1:8787/gpu.html`. לוחצים **העתקת התוצאה**. אם כתוב `"vendor": "intel"`, מטפלים בזה לפי ההוראה בסעיף 5 ופותחים את הדף שוב.
3. פותחים את העורך דרך הקישור שבשורה **Editor (owner)** (סעיף 4).
4. מוסיפים לציר הזמן **שני סרטונים** אחד אחרי השני. כדי שיהיה חומר למעבד, מקצרים מעט את סוף הסרטון הראשון (כך נשאר בקובץ חומר אחרי סוף הקליפ). אם מופיעה הודעה שאין חומר למעבד, זו הסיבה.
5. בוחרים את הקליפ **השני** (המעבר נמצא בתחילתו). בלשונית **קליפ** פותחים את **גלריית אפקטים** ועוברים ללשונית **מעברים**. את שבעת המעברים מוצאים בקבוצות **אור** (צריבת פילם, דליפת אור), **מסכה** (כתם דיו, שני מכחולים) ו**נייר** (שני הדפדופים).
6. מעבירים את העכבר על כל אחד משבעת המעברים, אחד אחרי השני, ורואים את התצוגה החיה. אם על אריח כתוב «דורש כרטיס מסך», הדפדפן לא מזהה כרטיס מסך; חוזרים לשלב 2 ושולחים את התוצאה.
7. לוחצים על אחד המעברים כדי להחיל אותו על הקליפ.
8. מייצאים סרט קצר: בכפתור **ייצוא** שבראש העורך. מחכים לסיום ופותחים את הקובץ.
9. שולחים לי שלושה צילומי מסך:
   - דף בדיקת כרטיס המסך (`gpu.html`) אחרי **העתקת התוצאה**;
   - הגלריה פתוחה עם תצוגה חיה של מעבר אחד (בזמן שהעכבר עליו);
   - הפריים מאמצע המעבר בסרט המיוצא (עוצרים את הסרט באמצע המעבר ומצלמים).

אם מעבר נראה שבור, ריק או שחור, מציינים את שמו בהודעה.

### 11. חבילת חנוכה

> **מה נבדק:** החבילה והפרקים שלמטה נבדקו כאן, בסביבת הפיתוח, על תמונות בדיקה בלבד. הם לא נוסו על המחשב שלכם ולא על צילומים אמיתיים. שמות הכפתורים הועתקו מקובצי הטקסטים של העורך; מה שלא הצלחתי לאמת מסומן.

1. בעורך, ברצועת הלשוניות שבצד, פותחים **תבניות**. הקטע הראשון בפנים נקרא **חבילות**. לוחצים על **חנוכה** (הכפתור «פתיחת החבילה חנוכה»). בתקופה שליד החג החבילה מופיעה גם כהצעה עם הכיתוב «מוצע לפי התאריך».
2. דרך אחרת: בתבניות, בוחרים את הסינון **חג**. ארבע התבניות של חנוכה מסומנות בסוג הזה.
3. בחבילה בוחרים תבנית: **הדלקת נרות**, **שמונה לילות**, **מסיבת חנוכה** או **ברכת חנוכה**, ולוחצים **פתיחת התבנית**. נפתח חלון עם ארבעה שלבים: **תמונות וסרטונים**, **מוזיקה**, **טקסטים**, **תכנון והחלה** (כפתורים **הבא** ו**הקודם**).
4. בשלב הטקסטים מופיעה קבוצה בשם **פרטים**. ממלאים בה את **הנר** (הלילה) או **שם** (למשל את שם המשפחה). אם מופיעה האפשרות «צולם בהדלקת הנרות של אותו ערב», אפשר לסמן אותה, ואז התוכנה מחשבת בעצמה את הלילה מתאריך הצילום; ואפשר גם לבחור **מספר הנר** ידנית או **בלי נר**. שדה שנשאר ריק משאיר את הנוסח החלופי של הכותרת («חנוכה שמח» ודומיו).
5. לוחצים **השתמש**. התבנית מסדרת את הקליפים והכותרות על ציר הזמן, והכול נשאר עריך.
6. מוזיקה מובנית: ברצועת הלשוניות פותחים **אודיו**, ובה את הלשונית **מוזיקה מובנית** (לחבילת חנוכה מתאימים הסגנונות «חגיגי» ו«רגוע ונעים»). **השמעה** מאפשרת להאזין לפני שמוסיפים, ו**הוספה לציר הזמן** מכניסה את המוזיקה בתחילת הסרט, ברצועת קול. **לא אימתתי** שחלון התבנית עצמו מציע מוזיקה מובנית: בשלב «מוזיקה» שלו הטקסטים מדברים על קובצי מוזיקה מהספרייה, ולכן המוזיקה המובנית מתווספת מהלשונית הזאת.
7. מייצאים כרגיל: לשונית **מסירה** ← **ייצוא**.

אף אחד עדיין לא האזין למוזיקה המובנית (היא מסומנת «עוד לא הושמעה לאף אחד»). הניסוחים של החבילה נמצאים לבדיקתכם ב-`docs/OWNER_REVIEW.he.md`.

### 12. קו החיים ופרטי המשפחה

> **מה נבדק:** גם כאן, הכול נבדק בסביבת הפיתוח על תמונות בדיקה, לא אצלכם ולא על צילומים אמיתיים. קבצי HEIC (ברירת המחדל באייפון) עדיין לא נקראים לתאריך, ולכן הם יופיעו תחת «בלי תאריך» וצריך לקבוע להם תאריך ידנית.

**תאריכי צילום.** בספרייה (הלשונית **מדיה**), המסמן **תצוגת הספרייה** מציע **הכול**, **לפי תאריך** ו**אירועים**. הכפתור **קריאת תאריכים מהקבצים** קורא את תאריך הצילום מכל הקבצים וכותב כמה נמצאו. קבצים בלי תאריך מופיעים בקבוצה «בלי תאריך». תאריך שנלקח משם הקובץ מסומן **משוער משם הקובץ**. בתפריט הקובץ, **תאריך צילום…** פותח חלון לקביעת תאריך ידנית (**שמירה**, **הסרת התאריך**), ו**הזזת השעון…** מתקן כמה קבצים יחד כשהשעון במצלמה היה שגוי.

**אירועים.** **סידור לפי אירועים** מקבץ את הקבצים עם התאריך לפי מועד הצילום. בתפריט האירוע: **שינוי שם**, **מיזוג עם הקודם**, **פיצול מכאן**, **הסרת הקיבוץ**, **הוספת האירוע לציר הזמן**. אירוע בלי שם נקרא לפי התאריך או לפי החג.

**שאלת השקיעה.** התאריך העברי מתחלף בשקיעה, לכן לאירוע שנוגע בערב מופיעה השאלה **מתי צולם?** עם התשובות **לפני השקיעה** ו**אחרי השקיעה**. עד שתבחרו, לא יוצגו תאריך עברי ושם חג לקבצים האלה.

**תאריך חי בכותרת.** בוחרים כותרת בציר הזמן ובתפריט **שדות בכותרת** לוחצים **הוסף שדה**: **תאריך צילום**, **תאריך עברי**, **שנה**, **שנה עברית** או **שם האירוע** (ויש אפשרויות תבנית כמו **במספרים** ו**בלי שנה**). השדה מתמלא מתאריך הצילום של הקליפ שמתחת לכותרת. **קבע כטקסט רגיל** הופך אותו לטקסט קבוע. (לא אימתתי מאיפה בדיוק פותחים את תפריט השדות: מצאתי רק את שמו ואת הכפתור, לא את הלשונית שבה הוא מוצג.)

**גיליון האנשים.** בלוח הפקודות הפקודה **אנשים…** פותחת את הגיליון, וגם **הוספת אדם…** בתפריט השדות של הכותרת. לכל אדם: **שם**, **תאריך לידה** (עם התאריך העברי לידו), והמילה לפני הגיל: **בן**, **בת** או **— (גיל)**. עם זה אפשר להוסיף בכותרת שדות **גיל: שם** ו**גיל במילים: שם** (למשל «בן 4» או «בן ארבע»). אפשר גם **העתקה מפרויקט אחר**. אדם שכותרות עדיין משתמשות בו אי אפשר להסיר עד שקובעים אותן כטקסט רגיל.

**מה סוכן מחובר רואה.** השמות ותאריכי הלידה נשמרים בקובץ הפרויקט, במחשב הזה. סוכן מחובר מקבל את **השמות בלבד**: לא את תאריכי הלידה ולא את הגילים שמחושבים מהם (בכותרות הם מוצגים לו ריקים, וייצוא שמציג גיל נחסם בפניו), אלא אם נתתם לו הרשאה לתאריכי לידה. גיל שנקבע כטקסט רגיל, או שהוקלד בכותרת או בשם של אירוע, גלוי לו כמו כל טקסט אחר.

**ארכיון בלי פרטי משפחה.** בלשונית **מסירה**, בקטע **ארכיון פרויקט**, ליד **הורדת ארכיון** יש את האפשרות **בלי פרטי משפחה**. הארכיון ייכתב בלי האנשים: שדות של שם וגיל ייקבעו כטקסט רגיל כפי שהם מוצגים כעת, וקובצי המדיה לא משתנים. אם יש כותרות שמשתנות לאורכן או שדות בלי נתון, העורך מציג רשימה לפני ההורדה.
