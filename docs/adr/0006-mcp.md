# ADR-0006: MCP transport and SDK

Status: accepted (Phase 0)

## Decision
Use the official v2 TypeScript SDK: `@modelcontextprotocol/server` 2.4.0 (and `@modelcontextprotocol/client` 2.4.0 in tests).
Its README states it implements the 2026-07-28 specification. `createMcpHandler` serves each request statelessly with a fresh server
instance; 2025-era clients are served by its stateless legacy fallback. Project state lives in the Store and is addressed by explicit `projectId`.

Verified in the proof: a client pinned to `2026-07-28` connects and edits; a default (2025-11-25 handshake) client is served by the fallback.

Note: `@modelcontextprotocol/sdk@1.32.2` (npm `latest` for the old package name) only implements up to 2025-11-25, so it was rejected.

Authentication is done by our code before the SDK is called; the verified principal is passed as `authInfo`. Tool annotations are hints only.

## Not yet done
Tasks extension (jobs are plain `jobId` + `get_job`), resources, prompts/playbooks, `subscriptions/listen`, MCP App, OAuth, tested third-party clients
(only the official SDK client has been exercised), stdio transport.
